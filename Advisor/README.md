# 文明6 顾问（Civ6 Advisor）

一个能**查游戏规则库**的问答助手。你问它答 —— 但答之前它会先去查游戏文件里的
权威数据，而不是凭记忆瞎编。

```
你 > 圣地相邻加成怎么算

  · 我查一下圣地的规则。
  [1] 查 kb_district (name=圣地)

圣地最划算的是贴着山脉（每格 +1）和自然奇观（每格 +2）；
相邻区域和树林是每 2 个才 +1，也就是每个只加 0.5，别算错。
```

两种用法：命令行里问，或者让它**浮在游戏画面上** —— 游戏里有个按钮，点一下就能问。

> **声明：代码、注释、文档、图标全部由 AI 生成。** 人类作者负责提出需求、试玩、
> 判断对错、决定取舍。所以请带着怀疑阅读 —— 能实测的结论都留了证据
> （`python selftest.py`，170 项，不联网不碰游戏），**没验证过的地方会写明"未验证"**。

---

## 它和普通 AI 聊天有什么不同

普通 AI 只能凭训练时记住的东西回答。文明6 的数值改过很多版，它经常记错，
而且**答得特别自信**。这个助手会自己动手查：判断需要什么资料 → 调工具去规则库查
（一次不够再查一次）→ 拿着真实数据组织答案。查不到时它会直说「规则库里没有这条」，
而不是编一个。

**玩家黑话也认得。** 问「奶妈强不强」它不会卡住：先把全部 133 个单位的名字过一遍，
认出游戏里管这叫「医疗兵」，再去查详情。这不是猜相似度，也不是查同义词表，而是
**把名单摊开看** —— 模型本来就懂"奶妈 = 治疗单位"，缺的只是"游戏里叫医疗兵"。

## 快速开始

需要：文明6（有资料片更好）、一个 API 密钥、**Python 3**。

> 这是**开发仓库**，不发预编译的 exe —— 要么直接用 Python 跑，要么自己打包出一个。
> 两条路都需要 Python，所以先把 Python 装好（微软商店版就够，自带 tkinter）。

### 1. 跑起来

**推荐：双击 `launch_overlay.bat`** —— 浮窗直接起来，不用编译。

想要一个能双击、不依赖 Python 的 exe：**双击 `build_exe.bat`**，等一两分钟，
同目录会出现 `文明6顾问.exe`（12.7 MB，自带运行时，拷给别人也能用）。
它打包前会先检查环境，缺东西会告诉你该敲哪条命令。

也可以用 `run.bat`（命令行版，能看到它每一步在干什么）。

> 仓库里没有 `text_patch.json`（要从你自己装的游戏里生成），
> 第一次启动会自动生成，不用管。

### 2. 配一个 API 密钥

**默认不预设任何服务商** —— 任何 OpenAI 兼容接口都能接。第一次启动时浮层会自动把
「设置」打开，填三项：**API 地址 / 模型名 / API 密钥**。

不想查地址的话，面板顶上有个「常用服务商」下拉，选一家就自动填好：

| 服务商 | 接口地址 | 模型名示例 |
|---|---|---|
| DeepSeek | `https://api.deepseek.com/v1` | `deepseek-chat` |
| 通义千问 | `https://dashscope.aliyuncs.com/compatible-mode/v1` | `qwen-plus` |
| 智谱 GLM | `https://open.bigmodel.cn/api/paas/v4` | `glm-4-flash` |
| OpenAI | `https://api.openai.com/v1` | `gpt-4o-mini` |

自建或公司内网的接口也一样：选「通用（自己填）」。地址写得很随意也认 ——
只写 `api.deepseek.com` 也能用（自动补 `https://` 和 `/chat/completions`）。
费用极低，用便宜款模型问一次大约一分钱人民币。

### 3. （推荐）装游戏内的按钮

不装也能用（`Ctrl+Alt+A` 随时叫出浮窗），但装了顺手得多。

**① 游戏改成「无边框窗口」**：选项 → 视频 → 显示模式 → 无边框窗口。

> 必须做。独占全屏会挡住所有外部窗口，这是 Windows 的机制，绕不过去。
> 无边框窗口看起来和全屏一样，不影响玩。

**② 把 `AdvisorMod/Civ6AdvisorBridge` 整个文件夹**复制到：

```
%USERPROFILE%\Documents\My Games\Sid Meier's Civilization VI\Mods\
```

然后启动游戏 → **额外内容** → 启用 `Civ6 AI Advisor Bridge` → 进地图。

> 改过 mod 的 Lua/XML 后，用 `sync_mod.bat` 一键同步，再**重启游戏**才生效。
> mod 本身的细节（它发什么信号、日志怎么看、四个文件各是什么）
> 见 [`AdvisorMod/README.md`](../AdvisorMod/README.md)。

### 4. 用起来

1. 打开顾问窗（双击 `launch_overlay.bat`，或你自己打包出来的 exe）
   > 打包版第一次启动要等 4 秒左右 —— 单文件 exe 得先把自己解压到临时目录；
   > 用 `launch_overlay.bat` 则几乎是秒开。
2. 进游戏、进到地图里
3. **右上角、文明百科按钮旁边**多出一个按钮 → 点它 → 顾问窗浮出来
4. 在窗口最底下那行打字（`>` 后面），回车
5. `Esc` 收起

## 怎么用

直接打字问，中文就行：`圣地相邻加成怎么算` / `剑客和枪兵哪个强` /
`宜居度低了会怎么样` / `秦始皇有什么特性` / `铁和 Horses 有什么区别`。

| 命令行 | 作用 |
|---|---|
| `/reset` | 清空对话历史（浮层里等于 `Ctrl+L`） |
| `/tools` | 看它一共有哪些查询能力 |
| `/exit` | 退出 |

| 浮窗操作 | 效果 |
|---|---|
| 点游戏内按钮 / `Ctrl+Alt+A` | 叫出窗口，并**重新读一遍当前局面** |
| `Esc` | 收起（程序继续在后台待命） |
| `Ctrl+L` | 清空对话，**界面和模型记忆一起清** |
| 标题栏「设置」 | 改接口 / 模型 / 密钥，保存后立刻生效 |

窗口用游戏自己的中文字体和从游戏 UI 里提取的配色，看起来像游戏的一部分。

## 它能看到什么

点按钮的那一刻，游戏会把当前局面导出一份给助手：

- 第几回合、什么时代、哪个文明 / 领袖
- 金币与收支，科技 / 文化 / 信仰产出
- 正在研究的科技、市政，各走了百分之几
- 在跟谁打仗
- 每座城市的人口、在造什么、还要几回合
- 军队构成（按兵种数个数，不列每个兵在哪）
- **地图**：每座城市周围 2 格（5×5）里**已探明**格子的地形统计，以及资源方位

> 它不是一直盯着 —— 数据只在点按钮那一刻导出。想看最新的，再点一次。

## 配置

**密钥不在 `config.json` 里**，单独一个 `secret.json`（已被 `.gitignore` 排除）。
理由：`config.json` 是可以给出去的东西，密钥不是；混在一起，"把配置贴出来看看"
就会把密钥带出去，提交到 Git 更是一泄到底 —— 而且 **Git 历史删不干净**。

也可以完全不落盘，用环境变量（优先级最高）：

```
set ADVISOR_API_KEY=sk-xxxx
```

其它上限都在 `config.json`（模板见 `config.example.json`）：`temperature`、
`timeout`、`max_steps`（一次提问最多查几步）、`max_turns`（保留最近几轮）、`proxy`。

## 仓库结构

```
Advisor/            浮层 + 大脑（Python）
AdvisorMod/         游戏内的按钮（mod：.modinfo + .xml + .lua，不含 AI 逻辑）
_tools/             写 mod 时的小工具（校验 .modinfo、从 .artdef 抽数据）
```

`Advisor/` 里的主要文件：

| 文件 | 干什么 |
|---|---|
| `agent.py` / `llm.py` / `tools.py` | 大脑：主循环、模型通信、工具说明书 |
| `kb.py` | 规则库：直接读游戏缓存，**离线可跑** |
| `overlay.py` / `theme.py` / `game_bridge.py` | 浮窗：界面、字体配色、监听游戏日志 |
| `paths.py` | 程序目录定位（打包后 `__file__` 会指向临时目录） |
| `selftest.py` | 自检 170 项 |
| `build_exe.bat` / `build_exe.py` | 打包出 `文明6顾问.exe` |
| `sync_mod.bat` / `sync_mod.py` | 把 `AdvisorMod/` 同步进游戏目录 |
| `launch_overlay.bat` / `run.bat` | 不打包直接跑（浮窗版 / 命令行版） |
| `build_text_patch.py` | 生成 `text_patch.json`（启动时自动跑） |
| `config.json` / `secret.json` / `config.example.json` | 设置 / 密钥 / 模板 |

只有 `agent.py` / `llm.py` / `tools.py` / `overlay.py` 需要联网；
`kb.py` 和游戏内那个 mod 完全离线。

## 出问题了

**跑起来 / 装起来**

| 现象 | 处理 |
|---|---|
| 一启动就问你要 key | 第一次运行的正常流程，粘贴回车，只此一次 |
| 启动时报编码错误 | 用 `run.bat` 启动，它处理了 Windows 的编码问题 |
| 双击 exe 后没看到窗口 | **先等 4 秒**。超过 10 秒还没动静，看同目录有没有 `overlay_error.txt`（完整报错） |
| 杀毒软件报 `文明6顾问.exe` | PyInstaller 的包**经常被误报**（启动方式像"自解压"）。加白名单，或改用 `launch_overlay.bat` |
| 浮窗浮不到游戏上面 | 显示模式还是「独占全屏」，改成「无边框窗口」 |
| 不小心开了好几个窗 | 结束 `文明6顾问.exe`（用 bat 起的话，进程名是 `pythonw.exe`，有的机器带版本号后缀如 `pythonw3.13.exe`），重新双击 |

**调用模型**

| 现象 | 处理 |
|---|---|
| `API key 不对或已失效` | 重新复制一次，别把首尾空格带进去 |
| `还没有填接口地址` / `模型名` | 程序不预设服务商，打开「设置」填，或在下拉里选一家 |
| `这个 key 没有权限调用当前模型` | 地址和模型名不是同一家的，在「设置」里重选 |
| `账户余额不足` | 去你用那家的后台充值 |
| `请求太频繁被限流` / `连不上服务器` | 等几秒再问；挂着代理的话把 `config.json` 里的 `"proxy"` 改成 `""` 试直连 |
| `规则库里没有这条记录` | 不是报错。游戏本身没给这东西写说明，助手没编造 |

**游戏内的按钮**

排查第一步永远是看 `%LOCALAPPDATA%\Firaxis Games\Sid Meier's Civilization VI\Logs\Lua.log`，
搜「**按钮就位**」—— 那行会说明走了哪条路，紧跟的「顾问按钮诊断」会打出屏幕尺寸、
上下文根尺寸、锚点和偏移。提 issue 时附上这两行，基本能直接定位。

| 现象 | 处理 |
|---|---|
| 点按钮没反应 | 先按 `Ctrl+Alt+A`。**弹出**说明浮窗没问题，是 mod 那边的事 |
| 日志里搜不到「按钮就位」 | mod 没加载。确认 `Mods\Civ6AdvisorBridge\Civ6AdvisorBridge.modinfo` 在位、且在「额外内容」里启用了 |
| 按钮和旁边的文字/图标轻微重合 | 锚点没跟原版按钮对齐（`StackChildAnchor()` 负责照抄）。改完 `sync_mod.bat` + 重启游戏 |
| 按钮压住了别的按钮 | 只在**退路**生效时才要调（日志写「先用退路 → 按屏幕…算了绝对坐标」）：改 `AdvisorLauncher.lua` 里的 `TOPBAR_KEEP_OUT`（越大越靠左） |

> 别改 XML 里的 `Anchor` / `Offset` —— 那两行只是 Lua 完全没跑起来时的兜底，
> 挂进顶栏时会被 Lua 覆盖。

**浮窗 / 回答**

| 现象 | 处理 |
|---|---|
| 找不到在哪打字 | 窗口**最底部**那一行，`>` 后面。点窗口里任何地方光标都会跳进去 |
| 输入框那行灰字删不掉 | 它不是输入内容，是叠在上面的一层提示，一打字就消失 |
| 浮窗说「这回没读到战局」 | mod 是旧版，`sync_mod.bat` 同步后重启游戏 |
| 战局数据看着是旧的 | 数据只在点按钮那一刻更新，再点一次 |
| 顾问说"某处有资源"但我没看到 | 它只知道**已探明**的格子。对不上就把浮窗里那些 `XX周围=` 的行贴出来 |
| 「本次 X token」是什么 | 这次问答的消耗。「命中缓存」那部分是每轮都发的固定开销（人格设定 + 16 个工具说明书），**计费便宜一个数量级** |
| 问很多轮会撑爆上下文吗 | 不会。自动滑掉最旧的轮次（默认保留最近 10 轮），并留一句「更早的 N 轮已省略」 |

## 已知局限

- **不能按条件筛条目**：问「有哪些远程单位」只能列出一部分 —— 工具给的是**纯名字
  清单**，不含射程、战斗力这些属性（库里实际有射程的单位是 46 个，它靠记忆挑，
  只能挑出十来个）。
- **不会自己开口**：得你去点按钮或打字问，它不会主动冒出"你这城缺粮了"。
- **不记笔记**：重开就忘了上一局聊过什么。
- **地图只看城市周围 2 格**，城市超过 8 座时只扫前 8 座并注明省略了几座。
- **不热生效**：改完 mod 的 Lua/XML 必须重启游戏。
